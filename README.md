# Jihan Aulia: Professional Portfolio & Automation Systems

> Portofolio interaktif dan etalase sistem automasi alur kerja (workflow automation) milik **Jihan Aulia**. Dibangun menggunakan **Vue 3** dan **Vite** dengan standar desain presisi bebas dari bias template generik AI (kepatuhan filter *antislop*).

---

## ⚡ Ikhtisar Portofolio

Website ini dirancang secara khusus untuk kebutuhan presentasi profesional kepada **Tech Recruiter (HR)** dan calon klien jasa automasi bisnis:

- **Mode Gelap Utama (Dark-First):** Palet *Deep Slate* (`#0b1118`), *Technical Teal* (`#14b8a6`), dan *Warm Amber* (`#f59e0b`) yang nyaman dipandang, dilengkapi tombol pengalih ke *Light Mode* yang memenuhi standar rasio kontras WCAG AA.
- **Simulator Alur Automasi n8n:** Visualisasi interaktif langkah-demi-langkah dari arsitektur integrasi sistem (Webhook &rarr; Validasi JSON &rarr; Sinkronisasi CRM &rarr; Broadcast WhatsApp Otomatis).
- **Integrasi Data Asli GitHub (@Najiann):** Mengambil data proyek publik secara langsung via GitHub API (`Inventory-Management-System`, `Stunting_Prediction`, `Stunting_Model_ML`, `CosRent`, `Tripz-bus`, dll.) dengan filter kategori dan pencarian instan.
- **Kredensial & Showcase Sertifikat Interaktif:** Menampilkan sertifikat Machine Learning (Dicoding x DBS), LSP/BNSP RPL, dan PT Mafi Global Asia dengan modal rincian kompetensi.
- **Panel Admin Rahasia (Owner-Only):** Pengelolaan data sertifikat lokal yang 100% tersembunyi dari pengunjung biasa dan hanya dapat diakses oleh pemilik portofolio melalui PIN atau URL rahasia.

---

## 🛠️ Tumpukan Teknologi (Tech Stack)

- **Frontend Framework:** Vue 3 (Composition & Options API)
- **Build Tool & Bundler:** Vite 8
- **Styling:** CSS3 Modern dengan CSS Custom Properties (Theme Tokens) & Scoped Styles
- **Accessibility:** Standar WCAG AA (Kontras warna &gt; 4.5:1, navigasi penuh via keyboard)
- **Deployment Target:** Vercel (Static / Edge Optimized)

## 🚀 Menjalankan Proyek Secara Lokal

Pastikan Anda telah memasang **Node.js (versi 18+)** di komputer Anda.

1. **Clone atau buka repositori:**
   ```bash
   git clone https://github.com/Najiann/portoo.git
   cd portoo
   ```

2. **Pasang paket dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan lokal:**
   ```bash
   npm run dev
   ```
   Buka peramban pada alamat: [http://localhost:5173/](http://localhost:5173/)

4. **Kompilasi bundel produksi:**
   ```bash
   npm run build
   ```
