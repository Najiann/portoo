# Design Direction: Jihan Aulia Portfolio

## 1. Identity & Personality
- **Name:** Jihan Aulia
- **Role:** Workflow Automation Engineer & Full-Stack Web Developer
- **Audience:** Tech Recruiters (HR) & Freelance Clients seeking practical automation (n8n, CRM, bots) and reliable web applications.
- **Personality:** Pragmatic, technical, disciplined, problem solver, transparent with real data.

## 2. Dial Configuration
Dial: ENERGY 2 / RHYTHM 2 / MOTION 2
- **ENERGY 2 (Balanced):** Professional tech clarity, authoritative typography, no blinding neon glow or purple orb clichés.
- **RHYTHM 2 (Varied & Purposeful):** Alternating content layouts (Hero statement -> Live Interactive Workflow -> Experience & Skills -> Interactive Certificate Showcase -> Filterable Live GitHub Repositories -> Interactive Contact & Admin Drawer).
- **MOTION 2 (Meaningful Transitions):** Functional state feedback, modal open/close with keyboard escape trap, real-time repository category filtering, clipboard feedback tooltips, and theme toggle transitions.

## 3. Color Palette
- **Primary Background (Dark):** `#0b1118` (Deep technical slate, avoids pure OLED black for comfortable reading).
- **Surface Elevation (Dark):** `#111c27` (Bordered with `#1e293b` for sharp architectural definition).
- **Primary Background (Light):** `#f8fafc` (Slate 50, crisp and clean).
- **Surface Elevation (Light):** `#ffffff` (Bordered with `#e2e8f0`).
- **Primary Accent:** `#14b8a6` (Teal 500, conveys precision, logic, and automation reliability).
- **Secondary Accent:** `#f59e0b` (Warm Amber 500, highlighting interactive actions and status badges).
- **Text Hierarchy (Dark):** `#f1f5f9` (Title), `#cbd5e1` (Body), `#94a3b8` (Muted/Meta).
- **Text Hierarchy (Light):** `#0f172a` (Title), `#334155` (Body), `#64748b` (Muted/Meta).

## 4. Typography
- **Font Stack:** `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Headline Weights:** 700 to 800 with tight letter-spacing (`-0.02em`) for punchy technical headers.
- **Body:** 400 to 500 with `1.6` line-height for effortless legibility.
- **Monospace Accents:** `'JetBrains Mono', 'Fira Code', monospace` strictly used for code tags, API endpoints, and repository metadata badges.

## 5. Architectural Levers
- **One focal point per screen:** Section headers lead directly into high-value interactive components.
- **Structural whitespace:** 3rem to 5rem section margins allowing distinct technical sections to breathe.
- **One deliberate accent:** Teal for technical markers and active states; Amber strictly for primary conversion CTAs and alerts.
- **Identity motif:** Pipeline node visualizer reflecting Jihan's expertise in n8n automation and workflow integration.

## 6. One-Line Justifications (R-31)
- **Why Deep Slate with Teal & Amber?** Delivers a focused engineering aesthetic requested for tech recruiters without relying on generic AI purple gradients.
- **Why an Interactive Workflow Pipeline?** Demonstrates actual n8n automation capability instead of just listing static keywords.
- **Why Modal Viewers for Certificates?** Allows recruiters to inspect credential details and verification notes without disrupting page flow.
- **Why a Local Admin Panel?** Empowers the portfolio owner to manage certificates dynamically while keeping full static deployment portability.
- **Why Live GitHub Filtering?** Solves missing repo descriptions by exposing real languages, dates, and direct links to actual repositories.
